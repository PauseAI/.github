# Security policy

This policy covers every public repository in the [PauseAI](https://github.com/PauseAI) organisation that doesn't have its own `SECURITY.md`.

## Please don't use public issues for these

Don't open a public issue, pull request or discussion if you've found:

- a **security problem**: a vulnerability, a leaked secret or key, a way to get access you shouldn't have, or anything that could be abused if it were public;
- a **personal data problem**: names, email addresses, phone numbers or other details about a person that are exposed, published by mistake, or handled in a way they shouldn't be.

Anything posted in a public issue can be read, copied and indexed straight away, even if it's deleted later.

## How to report privately

### 1. GitHub private vulnerability reporting (preferred)

1. Go to the repository the problem is in.
2. Open the **Security** tab.
3. Click **Report a vulnerability**.

Only you and the repository's maintainers can see the report. You can talk to us in it, and we can credit you when it's fixed if you'd like.

### 2. Email

If you can't use the button (you don't have a GitHub account, the button isn't there, or it's about personal data rather than code), email **[privacy@pauseai.info](mailto:privacy@pauseai.info)**.

Please include:

- which repository, website or page it's about;
- what you found and how to see it (steps, links, screenshots);
- what you think the impact is;
- how to reach you, if not by replying to the email.

Please don't include more personal data than you need to show the problem.

## What happens next

PauseAI is run mostly by volunteers, so we can't promise fixed response times, but we take these reports seriously. We'll acknowledge your report, look into it, and tell you when it's fixed. Please give us a reasonable chance to fix it before telling anyone else about it.

## Please don't

- access, change or delete data that isn't yours beyond what you need to show the problem;
- run tests that could disrupt our sites or services (load testing, spam, denial of service);
- try to trick or pressure PauseAI volunteers or staff.

Thank you for helping keep PauseAI and the people involved with it safe.
